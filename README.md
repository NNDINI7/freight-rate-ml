# Freight Rate Prediction — Spotter ML Engineer Assessment

Predicts `posted_rate` for freight loads with a LightGBM model, trained on
`data/train_test.csv`, and scores every load in `data/validation.csv`.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
# 1. Train + time-based validation (prints holdout MAE/RMSE/MAPE, saves model/)
python3 src/train.py

# 2. Fit the final model on all labeled data, write validation_predictions.csv
#    and fill data/december_chart_inputs_filled.csv
python3 src/predict.py

# 3. Validate outputs and render the December chart (provided scorer)
python3 src/score.py \
  --predictions validation_predictions.csv \
  --december-predictions data/december_chart_inputs_filled.csv
```

`score.py` writes `scorer_results/candidate_december.png`.

## Repo layout

```

src/features.py             shared cleaning + feature engineering
src/train.py                time-based holdout training + metrics
src/predict.py              final model fit on all labeled data + both prediction outputs
src/score.py                provided scorer (validates outputs, renders December chart)
model/                       saved model + fitted imputation artifacts (generated by train.py)
validation_predictions.csv   final submission (load_id, predicted_rate)
scorer_results/               candidate_december.png + supporting EDA charts
report/                      PDF/DOCX write-up (validation approach, data-quality notes, December chart)
```

## Approach summary

- **Target**: `posted_rate`, modeled in log space with LightGBM (gradient-boosted trees).
- **Split**: time-based holdout (last 15% of dates in `train_test.csv`), not a random
  split — `validation.csv` is entirely Nov/Dec 2025, chronologically after the labeled
  data, so the holdout is built the same way to give an honest read on out-of-sample
  accuracy. See `report/` for full reasoning.
- **Data-quality fixes**: sign-flipped `weight` values restored via `abs()`; missing
  `weight` imputed with the training median; missing `market_index` imputed from the
  same-date market average (it behaves like a shared daily index, not per-load noise).
- **December fixed-lane rows** (`data/december_chart_inputs.csv`) don't include
  `market_index`/`quote_signal`. `market_index` is recovered exactly from the combined
  train+validation daily average (full year coverage); `quote_signal` is filled with the
  historical median for the Lexington→Fort Wayne / Dry Van lane, since quote_signal is
  noisy per-shipment rather than date-predictable (documented in the report).
- **Holdout performance**: MAE ≈ $119, MAPE ≈ 5.4%, ~97% of predictions within 10% of
  actual.
